# Homebrew tap for Axel

```bash
brew install scarce/axel/axel
```

[Axel](https://axel.md) is agent orchestration, designed for Rex. Every commit on
`main` of [scarce/axel](https://github.com/scarce/axel) that passes CI is released,
and its release workflow moves `Formula/axel.rb` here, so `brew upgrade` always
brings you the newest build.

Use the full name `scarce/axel/axel`: Homebrew core has an unrelated `axel`.

Looking for Sonata? It moved to [scarce/homebrew-taps](https://github.com/scarce/homebrew-taps):
`brew install --cask scarce/taps/sonata` (existing installs migrate on their own).
